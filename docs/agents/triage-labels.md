# Triage labels

Use the same label strings as the canonical triage roles.

| Label | When to apply |
| --- | --- |
| `needs-triage` | The maintainer needs to assess the issue. |
| `needs-info` | The issue needs more information from the reporter. |
| `ready-for-agent` | An agent can implement the specified work. |
| `ready-for-human` | The work requires a human. |
| `wontfix` | The maintainer has decided to close the issue without implementing it. |

# Логические копии для восстановления и обновления

Для `geodata` используем логический дамп и сохраняем глобальные объекты кластера отдельно. Такой комплект можно восстановить в независимом экземпляре и использовать при переходе между основными версиями PostgreSQL, сохранив прежний экземпляр для отката до возобновления записи. Копия даёт восстановление до момента снимка. Восстановление на произвольный момент потребовало бы физической копии и архивирования WAL.
